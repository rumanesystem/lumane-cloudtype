# 챗봇 신규 상품 견적 보완 — 구현 범위와 검증

상태: 로컬 구현·자체 리뷰·검증 완료, 담당자 PR 검토 대상. 기존 조사 보고서에 대한 2026-11-03 후속 승인 범위.

18:21 후속 승인에 따른 실제 로컬 브라우저·모의 저장 검수와 추가 수정은 [PR91 브라우저 검수](chatbot-pr91-browser-review-20261103.md)에 기록했다. 아래 112개 테스트 결과는 최초 커밋 기준이며 후속 결과는 **117/117**이다. 동일 세션의 자체 리뷰이며 독립 리뷰나 운영 실증을 뜻하지 않는다.

## 구현 계획

1. 더도어는 제품·형태·면별 mm·옵션 수량을 명시한 한 메시지를 계산 입력으로 사용한다. AI가 길이·수량을 추정하지 않는다. 누락/모호 입력은 입력 예시로 되돌린다. 수정 시 전체 입력을 다시 받는다.
2. 총 길이 300mm당 1자, 잔여 150mm부터 올림, 최소 10자, 자당 120,000원과 승인된 전용 옵션을 순수 함수로 계산한다. 결과는 **기본·옵션 예상 소계**이며 배송·할인·VAT·시공 조건 미확정 안내를 동반한다.
3. 팬트리는 제품·형태·면별 mm·2~7단 입력 확인까지만 제공한다. 현행 B2C 칸수 계산은 공간 위상 의존과 분할 실패 시 대체 처리까지 포함하므로 이 작은 변경에서 통째로 복제하지 않는다. 자동 칸수·총액은 미완성으로 명시한다.
4. 신규 상품 안내는 서버가 생성하고 기존 메시지 JSON에 제품·입력·산정 근거를 보존한다. 미확정 소계를 상담 estimated_price나 CRM 최종금액으로 기록하지 않는다. 제품 전환/복원 시 과거 1post 금액이 신규 제품에 붙지 않도록 한다.
5. 기존 1post의 가격·배송·할인 지침은 수정하지 않는다. 기존 금액 추출/저장 경계만 회귀 테스트로 보완한다: 템플릿 감지, 할인 후/최종 금액 우선, 수정 견적의 CRM 가격 반영. CRM 상태·담당자 등은 수정하지 않는다.

## 검증과 반환

- 새 계산/입력 테스트, 네트워크 없는 서버 함수·채팅 경로 mock 테스트, 기존 서버 테스트, 문법 검사와 diff 검토.
- 더도어 149/150/151mm 경계, 최소가, 다면 합산, 전용 옵션과 잘못된 입력, 신규 상품 미확정 금액 저장 방지, 1post 회귀·재시도·복원 검증.
- 현재 feature branch에서만 commit/push/PR. 저장소 배포 workflow는 main push만 대상이며 PR workflow는 검사 전용. GitHub repository webhook 목록은 비어 있음을 확인했다.
- 운영 요청·DB migration·실제 알림·배포·main push·merge·auto-merge는 수행하지 않는다.
- 롤백: 이 feature 변경을 채택하지 않으면 기존 main 동작이 유지된다. 운영 배포 없이 검토 PR로 반환한다.

## 구현 결과

- 더도어의 기본가·옵션 **예상 소계** 계산 완료. 지원 형태는 ㅡ/ㄱ/ㄷ/11/ㅁ자이며 실제 시공 가능·도면 제공을 확정하지 않는다. 측판·기둥 자동 추가 없음.
- 입력 예: `더도어 ㄱ자; A=1575mm; B=1575mm; 옵션=2단서랍:1` → 11자 기본 1,320,000원 + 옵션 150,000원 = 소계 1,470,000원. 최종금액은 미확정.
- 팬트리 입력 예: `팬트리 ㄱ자; A=1115mm; B=1235mm; 단수=7` → 입력을 보관하고 일반·코너 칸수 확인 필요 안내. **팬트리 자동 견적은 미완성**이며 기본가만으로 완성 견적처럼 안내하지 않는다.
- 한 메시지에 전체 입력을 받는다. 필수 옵션 표시가 없거나 단위·수량·옵션이 모호하면 재입력을 요청한다. 여러 턴의 자연어에서 자동으로 치수와 옵션을 합치는 기능은 포함하지 않았다. 유효성 검사 상한(mm 100,000, 옵션별 수량 100)은 입력 방어 범위이며 실제 제작 가능 범위를 뜻하지 않는다.
- 제품·입력·계산 버전·소계는 기존 메시지 JSON의 `quotePreview`에 보관한다. 신규 상품의 상담 `estimated_price`는 null이며 quotes/CRM 자동 견적 등록을 하지 않는다. 기존 1post 접수 이력은 삭제하지 않는다.
- 신규 상품 안내에는 기존 1post 옵션 선택 버튼이 뜨지 않는다. 담당자 상담 요청에는 기존 카카오 채널을 안내하며 실제 연결·발신을 실행하지 않는다.

- 재현 후 보완: 총합만 있는 답변/금액 템플릿 저장 누락, 할인 전 금액 오선택, 수정 견적 CRM 금액 미반영, 전화번호 입력 시 과거·현재 견적 저장 경합.
- 추가 자체 리뷰에서 과거 이벤트 재전송의 최신 금액 덮어쓰기와, 신규 상품 상태로 재시작 후 1post로 돌아갈 때 접수 상태 초기화 가능성을 재현해 차단했다. CRM 수정은 가격과 변경 시각만 갱신하고 기존 상태·담당자를 보존한다.
- 제품 전환·저장 실패 후 동일 이벤트 재시도·재시작 복원·팬트리 미확정 금액·기존 1post 복귀를 실제 채팅 처리 함수의 mock 테스트로 검증했다.
- 기존 1post 가격/할인/배송 지침 파일 변경 없음. DB schema·migration·배포 workflow 변경 없음. DS/B2C 파일 변경 없음.

## 남은 조건

- 신규 제품의 챗봇 채널 배송·할인·VAT·시공 조건 확정.
- 팬트리 검증된 칸수 계산 연결과 총액 계산.
- 실제 LLM/운영 데이터 검증은 이번 승인 범위 밖. 안내 문구의 담당자 검토 필요.
- 신규 상품 계산은 명시 입력 기반의 제한된 안내이다. 후속 검수에서 상품 설명·일반 상담과 계산 입력을 분리하고, 실제 로컬 브라우저 대표 흐름을 검증했다. 자유로운 자연어에서 치수·옵션을 합성하는 기능과 실제 모델·운영 지침 일치는 여전히 미검증이다.
- 기존 짧은 AI 견적번호의 연결·전환 절차와 새 번호의 DB 길이 수용 확인은 운영 적용 전 조건이다. 소유가 불명확한 기존 행은 자동 갱신하지 않는다.
- 기존 1post 전체 지침 간 충돌이나 모든 비정형 견적 파싱을 해결한 것은 아니다. 이번 변경은 재현한 금액·저장 경계에 한정한다.
