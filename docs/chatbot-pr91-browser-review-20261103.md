# PR91 로컬 브라우저·저장 검수

2026-11-03. 기존 Draft PR91의 승인된 후속 작업. **리뷰어는 구현한 동일 세션**이며, 별도 파일·함수 리뷰 패스를 수행했다. 독립 리뷰·실제 모델 평가·운영 DB 검증은 아니다. merge·배포 없이 검토 초안을 유지한다.

## 검수 환경과 한계

- ego-browser 전용 TaskSpace에서 실제 `chat.html`, `js/chat.js`, `js/ui.js`로 입력·전송·새 상담·새로고침·재방문을 실행했다. 사용자 탭은 사용하지 않았다.
- `node test/fixtures/chatbot-review.js`로 `127.0.0.1:43191`에만 바인딩한다. `server.js`를 import하지 않고 실제 채팅/등록 핸들러, 세션 직렬화·복구, 파서·저장 함수를 VM에 로드한다. `.env`, 운영 SDK, DB, 모델, Slack, CRM 연결은 없다.
- DB double은 필터·upsert·update를 실행하는 메모리 저장소이다. `/__fixture/restart`는 서버 세션 메모리만 비우고 저장된 행은 유지해 실제 hydration 함수를 검증한다. 디스크 내구성·실제 프로세스 재시작·Supabase 제약/RLS/트랜잭션 검증은 아니다.
- 모델·관련성 필터·토큰 기록과 상태 폴링은 대역이다. 1post의 10% 할인·30,000원 배송비 등은 **금액 추출 비교용 응답 fixture**로, 실제 정책 계산의 정확성을 증명하지 않는다. 실제 1post 지침 파일은 변경하지 않았다.
- 제공 응답에서만 API 주소를 로컬로 바꾸고 외부 폰트·아이콘·html2canvas·알림 권한 요청을 제외했다. CSP의 연결 대상은 self이다. 마지막 검수의 resource origin은 로컬 1개였다. 초회 CSS의 외부 import 시도는 CSP로 차단됐고 최종 fixture에서는 import도 제거했다. 외부 링크는 누르지 않았다.
- 모든 화면에 `LOCAL FIXTURE · 모의 모델/저장소 · 운영 연결 없음`을 표시했다. 기존 녹색 “AI ... 실제 연결” 배너는 서버 health 응답 표시이며 실제 모델 연결의 증거가 아니다. 폰트·아이콘·이미지 내보내기와 실제 모바일 키보드는 검수 대상에서 제외했다.

## 재현한 결함과 최소 수정

1. **상품 언급 뒤 입력 파서에 갇힘.** 변경 전 “더도어는 어떤 제품인가요?”와 “아직 이사 전이라 천천히 알아볼게요”가 모두 `needs_input`과 가격표를 반환했다. 견적·수정 입력만 엄격한 파서로 보내고, 상품 설명은 확인된 정보로, 일반 상담은 제품별 제한을 추가한 기존 모델 경로로 분리했다. 제품 문맥과 최종금액 저장 차단은 유지한다. 새 제품 상담에 과거 1post 재방문 금액 요약도 주입하지 않는다.
2. **연락처 저장 누락.** 세션에 연락처가 있어도 응답 주문서에 연락처가 없으면 `conversations.phone`이 null이었다. 기존 본문 추출값 다음으로 세션 연락처를 보존한다. 신규 상품 전환·복구 후 1post 수정 시에도 CRM 금액 갱신을 이어간다.
3. **다른 고객의 견적 덮어쓰기.** 끝 8자가 같은 두 합성 세션이 동일한 견적번호로 upsert되어 2개여야 할 행이 1개였다. 전체 세션 ID의 SHA-256 앞 32자(128bit)를 번호로 사용한다. 세션 ID 원문을 외부 견적번호로 노출하지 않는다. 새 번호 복구 시 기존 CRM의 가격만 갱신하며 상태·담당자는 유지한다.

기존 짧은 번호의 소유 관계는 추정하지 않는다. 새 번호가 없고 대응하는 짧은 번호가 있으면 자동 등록·갱신을 차단하고 `AI_QUOTE_IDENTITY_REVIEW`를 기록한다. 해당 견적 요청은 503 저장 오류로 반환된다. **기존 번호 연결·전환 절차가 마련되기 전 운영 적용 준비가 끝난 변경으로 간주하지 않는다.** 기존 데이터는 수정하지 않았다.

## 남은 조건

- 더도어의 승인된 300mm/자·150mm 올림·최소 10자·단가와 옵션은 구현 기준으로 확정 유지한다. 신규 제품의 채널 배송·할인·VAT·시공 조건은 미확정이다.
- 팬트리 자동 칸수·총액은 미완성이다. 범용 자연어 입력 합성·제품 설명 전체 지식·실제 모델의 지침 준수는 이번 fixture로 검증하지 않았다.
- 운영 전 기존 짧은 견적번호의 소유 관계와 전환 절차, `quote_number`의 38자 수용 여부·외부 연동, 실제 DB 권한/제약과 기존 데이터 호환을 별도로 검토해야 한다. 운영 조회·보정·배포는 이번 승인에 포함되지 않는다.
- 세션 직렬화는 기존과 동일한 단일 프로세스 범위이다. 분산 인스턴스 경합 검증은 포함하지 않는다.
- 담당자의 별도 코드·업무 검토가 남아 있다. Draft 유지, merge/auto-merge/main push/배포 금지.
