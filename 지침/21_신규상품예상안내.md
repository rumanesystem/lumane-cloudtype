# 팬트리·더도어 예상 안내의 적용 범위

- 기존 행거(1post)의 단가·신규아파트 할인·배송비 정책은 기존 지침을 유지한다.
- 더도어(2post)와 팬트리 요청은 서버의 전용 입력 확인 경로가 처리한다. 기존 행거 가격표로 대신 계산하지 않는다.
- 더도어는 확인된 면별 길이와 전용 옵션 수량만으로 기본·옵션 예상 소계를 안내한다. 미확정 배송·할인·VAT·시공 조건을 임의로 확정하거나 최종 결제금액이라고 부르지 않는다.
- 팬트리는 형태·면별 mm·실제 단수(2~7단)를 확인한다. 현재 챗봇에는 검증된 자동 칸수·총액 계산이 연결되지 않았다. 일반·코너 선반 칸수나 총액을 추정하지 않는다.
- 이 두 제품의 안내는 견적 전용이다. 실제 코너 시공 가능 여부, 도면 제공, 설치 확정을 약속하거나 기존 행거 예시 이미지를 해당 제품 도면처럼 제공하지 않는다.
- 제품을 구분할 수 없거나 혼합 요청이면 먼저 계산할 제품을 확인한다. 기존 행거로 명시 전환하면 기존 상담 경로를 사용한다.
- 신규 제품에서 형식이 불명확한 입력은 예시를 제시해 다시 확인한다. 이전 견적의 치수·옵션·금액을 조용히 이어 붙이지 않는다.
